# G.I.S.A. - Gastronomía Inclusiva y Seguridad Alimentaria

¡Bienvenido al repositorio principal del proyecto!

## Documentación

Toda la información técnica y legal necesaria para entender, instalar y utilizar este sistema se encuentra en la carpeta `/documentacion`, ubicada en la raíz de este mismo repositorio. 

Dentro de ese directorio encontrarás los siguientes archivos detallados:

* **Instalación:** Guía paso a paso para la puesta en marcha y despliegue del entorno.
* **Manual de Usuario:** Explicación clara sobre cómo interactuar con las diferentes funcionalidades de la plataforma.
* **Aviso Legal:** Condiciones de uso e información del responsable de la aplicación.
* **Política de Privacidad:** Cumplimiento del RGPD y tratamiento de los datos de usuarios.
